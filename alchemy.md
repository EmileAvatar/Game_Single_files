# Alchemy

## Alchemical System Overview

Alchemy transforms raw materials through a **three-tier processing system** into powerful consumables, creature enhancements, magical items, and spell components.

```
Raw Materials → Alchemical Essences → Final Products
(herbs, parts, mana) → (processed compounds) → (potions, creatures, items)
```

### Three-Tier Crafting Flow

```
TIER 1: Raw Materials
├─ Herbs (Healing, Stamina, Mental, Elemental, Toxic, Rare)
├─ Creature Parts (Organs, Blood, Bones, Hides, Fluids)
├─ Minerals (Ores, Crystals, Stones)
└─ Magical Essences (Mana, Life Essence, Soul Essence, Ichor, etc.)
         ↓
    [Alchemical Essence Extractor]
         ↓
TIER 2: Alchemical Essences
├─ Elemental Essences (Fire, Ice, Lightning, Earth, Poison, Acid)
├─ Vital Essences (Regeneration, Vitality, Youth, Fortitude, Mutation)
├─ Mental Essences (Clarity, Focus, Dreams, Madness, Wisdom)
├─ Physical Essences (Strength, Agility, Stone Skin, Flight, Invisibility)
├─ Transformation Essences (Lycanthropy, Transmutation, Petrification, Polymorph)
├─ Necromantic Essences (Undeath, Life Drain, Decay, Soul Binding)
└─ Divine Essences (Light, Darkness, Divinity, Resurrection)
         ↓
    [Alchemical Combiner / Alchemy Table / Bioforge / Enchanting Altar]
         ↓
TIER 3: Final Products
├─ Potions & Elixirs (Healing, Buffs, Transmutation)
├─ Creatures (Bioforged with enhanced abilities)
├─ Enchanted Items (Weapons, Armor, Jewelry)
└─ Spell Components (High-level spellcasting materials)
```

## Alchemy Skill Progression

### Essence Extraction (Skill 0-100)

* **Skill 0-20: Apprentice Extractor**
    * Can extract: Common herbs (Healing Herb, Stamina Herb)
    * Success Rate: 75%
    * Yield: 1 extract per 10 herbs
    * Processing Time: 150% base time

* **Skill 21-40: Journeyman Extractor**
    * Can extract: Uncommon herbs, basic creature parts
    * Success Rate: 85%
    * Yield: 1 extract per 8 herbs
    * Processing Time: 100% base time

* **Skill 41-60: Expert Extractor**
    * Can extract: Rare herbs, exotic creature parts, minerals
    * Success Rate: 92%
    * Yield: 1 extract per 6 herbs
    * Processing Time: 80% base time

* **Skill 61-80: Master Extractor**
    * Can extract: Legendary herbs, magical creature parts
    * Success Rate: 96%
    * Yield: 1 extract per 5 herbs
    * Processing Time: 60% base time
    * Bonus: 10% chance of double extract

* **Skill 81-100: Grandmaster Extractor**
    * Can extract: All materials including divine components
    * Success Rate: 99%
    * Yield: 1 extract per 4 herbs
    * Processing Time: 50% base time
    * Bonus: 25% chance of double extract
