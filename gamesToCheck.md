# Games to Check

## Purpose
Reference games with similar UI, crafting systems, and gameplay mechanics to study for design inspiration.

---

## Perfect Matches (Very Similar)

* **Geneforge Series**
    * Isometric 2D view with party management
    * Creature creation interface (bioforging)
    * Faction reputation system
    * Alchemy and crafting
    * Turn-based combat with abilities
    * Developer: Spiderweb Software

* **Avernum/Exile Series**
    * Same developer as Geneforge
    * 2D isometric world map
    * Character sheet with skills/attributes
    * Crafting stations (alchemy, smithing)
    * Quest journal and faction reputation
    * Similar UI layout philosophy
    * Developer: Spiderweb Software

## Crafting Systems to Study

### Three-Tier Crafting (Similar to Alchemy.md)
- **Terraria**: Raw ore → Bars → Equipment
- **Minecraft**: Raw materials → Processed → Crafted items
- **Divinity: Original Sin**: Ingredients → Essences → Potions

### Workstation-Based Crafting
- **RimWorld**: Specialized workbenches for each craft type
- **Project Zomboid**: Station requirements for advanced recipes
- **Dwarf Fortress**: Workshop quality affects output

### Essence/Component Systems
- **Path of Exile**: Currency items as crafting components
- **Grim Dawn**: Component system for item enhancement
- **Last Epoch**: Crafting affixes and essence extraction

## Notes

These games represent the best examples of UI and systems similar to your design. Priority should be given to playing/studying the Top 5 games, particularly Geneforge (as it's the direct template) and the modern implementations in Divinity: Original Sin 2 and Pillars of Eternity 2.

Focus areas when studying:
1. How information is organized and presented
2. How many clicks it takes to perform common actions
3. Keyboard shortcut implementations
4. Tooltip information hierarchy
5. Crafting station interfaces and material requirements display
6. Character progression clarity and visual feedback
